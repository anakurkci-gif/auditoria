# Аудитория — студенческий планер

Одностраничный учебный планер в эстетике пыльной розы и книжной типографики.

## Возможности

- Расписание пар на неделю с автоматическим числителем/знаменателем.
- Календарь посещаемости по каждому дню и паре, статистика месяца и список пропусков.
- Предметы: добавление, переименование и удаление.
- Конспекты: чтение, создание, удаление и краткая выжимка через ИИ.
- Карточки для запоминания с показом правильного ответа.
- Дедлайны: добавление, изменение и удаление.
- ИИ-репетитор на Gemini API (ключ вводится в браузере).
- Личное приветствие: имя хранится отдельно в каждом браузере.

## Данные

Всё хранится локально в `localStorage` браузера: у каждого устройства своя копия данных. Ключ API и имя никуда не отправляются, кроме запросов к Gemini.

## Локальный запуск

Откройте `index.html` в браузере. Для шрифтов, Tailwind и ИИ-репетитора нужен интернет.

## Публикация

Сайт размещён на GitHub Pages. Достаточно загрузить файлы в ветку `main`: `index.html`, папку `icons`, `manifest.webmanifest` и `.nojekyll`.
